口径与数据来源

  • 更新频率分三层，不是所有数字都实时。 ① 实时行情条（页面顶部那一排）= 浏览器每 60 秒直连腾讯行情，只有「价格 + 当日涨跌幅」， 标着绿色「实时」；
    ② 分数 / 倍数 / 分数历史曲线 / 近一月涨跌 / 长期锚 / 二十二年 = 跑批时整体重算， 每交易日 6 次（北京 08:07 / 10:07 / 11:17 / 13:37 / 14:47 / 15:17）， 区块标题右侧标着「每交易日 6 次」或「随跑批刷新」；
    ③ 宏观利率那排 = 日频数据，跟着跑批刷新，标着「日频」。
    所以：行情条每分钟在动，分数一天最多变 6 次。分数不会每分钟变，也不该每分钟变—— 它的输入（PE、股息率、国债利率）本身就是日频/周频的，日内只有价格在动， 每分钟重算只会让同一个分数在几分钱的价格波动里来回抖。
  • 分数方向：0–100，越高表示当下越便宜/越恐慌、越该多买。50 分 = 1.0 倍基准。
  • 带宽：≥82→2.0×　68–82→1.5×　56–68→1.2×　40–56→1.0×　28–40→0.8×　14–28→0.5×　<14→0.3×。 中性带 16 分宽，避免分数抖 1 分就换档。
  • 档内位置：同一倍数档内部的相对位置，越靠右越接近上调一档。同档多个标的用它排先后。
  • 评分一律用指数本身，不用基金净值。基金净值有三重失真：分红/折算造成单日跳降、QDII 的 T+1/T+2 披露导致日期错位、管理费持续侵蚀。
  • 申购状态不参与打分、不改倍数。同一份行情不该因为渠道临时限购给出不同倍率；限购只影响「钱能不能落到那只基金」。
